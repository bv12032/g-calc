# 加速度計算・2進数電卓

ブラウザで開くだけで使える計算ツールです。インストールは不要です。

## 加速度計算（G）

- 10地点ぶんのキロ程（m。「10,050」「10k050」も可）と速度（0.1 km/h 単位の整数。例：325 → 32.5 km/h）を入力します。地点1の速度は初期値 0 です。
- となり合う地点の間（区間）ごとに、距離・速度変化・加速度（G）・所要時間を計算します。
- 加速度基準値・減速度基準値（G）を超えた区間は、始まりの地点番号に「!」が付きます。押すと詳細へ移動します。
- 計算式：a = (v₂² − v₁²) ÷ (2 × 距離)、G = a ÷ 9.80665（区間の中は加速度が一定と仮定）

## 2進数電卓

- 足し算・引き算・掛け算・割り算（余りつき）、AND・OR・XOR・NOT、シフト
- 答えを2進・10進・16進・8進で表示
- 10進・2進・8進・16進の相互変換

## 使い方

`index.html` をブラウザで開きます。GitHub Pages で公開すると、スマホからも URL で使えます。
